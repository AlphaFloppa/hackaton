# Тестовые данные для API

Директория `test/` содержит данные для ручного и автоматического прогонов API.

## Структура

| Файл | Что это |
|---|---|
| `fixtures.sql` | Идемпотентный SQL с фиксированными UUID: города, ПВЗ, хаб, продавцы, покупатель |
| `scenarios/*.sh` | Полные сценарии (bash + curl): городской заказ, хаб+магистраль, возврат, ошибка, длительное хранение, завоз/приёмка |
| `smoke.sh` | Быстрый smoke-тест всех эндпоинтов |
| `README.md` | Этот файл |

## Загрузка фикстур

```bash
sudo -u postgres psql -d wildb < test/fixtures.sql
```

## Запуск сценариев

Базовый URL берётся из переменной `API` (по умолчанию `http://127.0.0.1:8000`):

```bash
symfony server:start -d          # если сервер не запущен
sudo -u postgres psql -d wildb < test/fixtures.sql

bash test/smoke.sh               # быстрый прогон всех эндпоинтов
bash test/scenarios/01_city_order.sh        # городской заказ (MESH)
bash test/scenarios/02_hub_trunk.sh         # межгород (HUB_TRUNK)
bash test/scenarios/03_return.sh            # возврат
bash test/scenarios/04_incident.sh          # логистическая ошибка
bash test/scenarios/05_long_storage.sh      # длительное хранение
bash test/scenarios/06_supply.sh            # завоз и приёмка партии
```

## Соглашения сценариев

- Каждый сценарий печатает проме…жуточные ответы и в конце краткий итог.
- Все POST используют фиксированные `Idempotency-Key` — сценарии можно перезапускать;
  при перезапуске «уже обработано» не ломает ход сценария.
- Сценарий 05 двигает время через `/system/time/advance` и в конце сбрасывает его.
